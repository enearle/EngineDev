## Phase 1 design

These decisions were made while reading the code. Change them if you find a reason, and say why.

### RHI additions

- **Frame ring allocator.** One host-visible buffer, uniform and storage usage, split into one
  region per frame in flight, bump-allocated and reset when that frame slot begins.
  `Allocate(size, alignment)` returns buffer handle, byte offset and mapped pointer. Alignment may
  be any multiple, not only a power of two. This fixes defect 5.
- **Per-frame uniforms.** Bind with an offset given at bind time, not stored on the set. Vulkan:
  `UNIFORM_BUFFER_DYNAMIC` over the ring buffer with the dynamic offset at bind. D3D12: make
  dynamic uniform buffers root CBVs (`SetGraphicsRootConstantBufferView`). The current D3D12 path
  rewrites a CBV descriptor in place, which races with frames still in flight.
  `SetIndexToBuilderIndex` needs to carry more than one root parameter per set.
- **Storage buffers.** Finish them on Vulkan (`AllocateDescriptorSet` never writes them today) and
  on D3D12 as structured-buffer SRVs. Bind the whole ring buffer once and index with an absolute
  element index, so the descriptor is never rewritten. Align each allocation to the element stride.
- **Images created empty.** `CreateImage` must support colour and depth attachments that are also
  sampled, array layers, and an optimized clear value. D3D12 depth that is sampled needs a
  typeless resource with a `D32_FLOAT` DSV and an `R32_FLOAT` SRV. Use the right SRV and RTV
  dimension for arrays. Add `R16G16_UNORM`.
- **D3D12 descriptor slots** need free lists (ranges), or resizes leak RTV, DSV and SRV slots.
- **Instancing.** Draw calls take an instance count. Pass the first-instance index as a small push
  constant and always draw with first instance 0, because `SV_InstanceID` includes the base on
  Vulkan and not on D3D12.
- **Shared layouts.** Let a pipeline reuse another pipeline's root signature or `VkPipelineLayout`.
  With bones in a storage buffer the skinned pipeline has the same layout as the static one, so
  the variant machinery (`IsVariant`, `VariantResourceLayout`, `VARIANT_DESCRIPTOR_SET_BASE`,
  `PipelineVariants`) can be deleted.
- Remove from `Pipeline`: owned attachments, `IOResource`, `InputPipelineIDs`,
  `CreateOwnAttachments`, `RecreateAttachments`. Keep formats, which the pipeline state needs.
  Remove the `void*` image and view parameters from the executor in favour of `ImageHandle`. The
  swapchain image becomes an `ImageHandle` too.

### Renderer

- **Pass graph** (`Renderer/PassGraph`). Retained, not rebuilt per frame. Scope is ordering,
  transient attachments, barriers and resize, and nothing more.
  - Passes declare colour writes with load op, a depth write, and sampled reads.
  - Order by topological sort; ties keep declaration order.
  - The graph creates the images and recreates them on resize.
  - Barriers: keep the current layout per image and emit a transition before each pass when the
    required layout differs. The back buffer starts each frame as `Undefined` and ends `Present`.
  - A pass names a pipeline layout and set index for its sampled inputs; the graph allocates that
    descriptor set and rewrites it on resize.
  - External passes are graph passes of an overlay kind, so `EnlistExternalPass` becomes a thin
    wrapper. If nothing has written the back buffer before the first overlay pass, clear it.
  - Gate: adding a pass needs no edits to the graph or `Renderer`. The standard shadow, G-buffer
    and lighting passes go in `Renderer/Passes` and use only the public graph API.
- **Mesh and material registries** with `MeshHandle` and `MaterialHandle`. The registry uploads
  vertex and index buffers and stores bounds and the vertex layout (static or skinned).
- **RenderScene snapshot**: objects (mesh, material, world matrix, bounds, bone range), bone
  matrices, lights, camera. The engine fills it once per frame; nothing outside the renderer
  submits draws.
- **Draw lists**, rebuilt per frame per view: frustum cull by bounding sphere, 64-bit sort key from
  pipeline variant, material and mesh, sort, merge equal neighbours into instanced draws. Write
  instance data (world, normal matrix, bone offset) to the ring in sorted order. Shadow and
  G-buffer passes each build their own list.
- **Slim G-buffer**: albedo `R8G8B8A8_UNORM`, octahedral normal `R16G16_UNORM`, material
  `R8G8B8A8_UNORM`, depth `D32_FLOAT` sampled. Rebuild world position in the lighting shader from
  depth and the inverse view-projection. Target is about 59 MB at 2560 x 1440.

### Engine

- Keep `SceneNode` and components as the scene. Add material handles per submesh to
  `MeshComponent`. An extraction step walks the scene each frame into the `RenderScene`.
- Delete `TempGameObject`. `DerpMover` writes bone matrices into scene data, not a mapped buffer.
- Camera and lights go into the snapshot. `Camera` currently subscribes to the resize event and
  never unsubscribes; fix that while it is being reworked.
- `Uploader` can go once nothing uses it.
