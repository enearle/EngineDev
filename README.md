# EngineDev

A C++23 renderer and engine for Windows with Vulkan 1.3 and Direct3D 12 backends. The plan and its
status are in [Docs/RendererPlan.md](Docs/RendererPlan.md). Machine setup in detail is in
[SETUP.md](SETUP.md).

## Layers

| Project | Output | Holds |
| --- | --- | --- |
| `RHI` | DLL | Device, resources, pipelines, command recording, both backends |
| `Renderer` | DLL | Pass graph, standard passes, registries, draw lists, readback, mip generation, HLSL |
| `Engine` | DLL | Scene, assets, input, UI layers (NoesisGUI, Dear ImGui) |
| `Game` | DLL | Game code and its assets |
| `Editor` | EXE | Dear ImGui editor |
| `Standalone` | EXE | Runtime host |

## Build

1. Visual Studio 2022 with the *Desktop development with C++* workload (MSVC 14.39 or newer).
2. The LunarG Vulkan SDK, which sets `VULKAN_SDK`. Its `dxc` compiles the shaders during the build.
3. The NoesisGUI 4.0.1 Native SDK, which is not in the repository. Extract it to
   `External/NoesisGUI-NativeSDK-win-4.0.1-Indie` or point `NOESIS_SDK` at it, then build
   `NoesisApp` once:

   ```
   msbuild <NoesisSDK>\Src\Projects\NoesisApp\windows_x86_64\NoesisApp-vs2022.vcxproj -p:Configuration=Release -p:Platform=x64
   ```

4. Build the solution, Debug or Release, x64 only:

   ```
   msbuild Solution\Engine.sln -m -p:Configuration=Debug -p:Platform=x64
   ```

The Noesis and assimp DLLs are copied next to the executables by the build. The project files are
generated by `Tools/GenerateProjects.py`; rerun it after adding or removing source files.

## Run

The working directory must be the project directory, `Solution/Standalone` or `Solution/Editor`,
because runtime paths are relative to it.

| Switch | Effect |
| --- | --- |
| `-vulkan`, `-dx12` | Choose the backend. Standalone defaults to Vulkan, the Editor to Direct3D 12 |
| `-play` | Editor only: start in play mode |
| `-stress` | Add a grid of 10,000 objects; batch counts show in the Renderer panel |
| `-freeze-animation` | Hold the animated test mesh still, for comparing captures |
| `-novsync` | Present without waiting for vertical blank, on both backends |
| `-compute-test` | Run the Phase 2 gate test; prints `Compute test: ...` on exit |
| `-animation-test` | Run the Phase 3 checks; prints `Animation test: ...` and `Skinning test: ...` on exit |
| `-crowd N` | Add N animated copies of the character (100 when N is left out), cross-fading on a timer |

In Debug builds the Vulkan validation layer and the Direct3D 12 debug layer print to stderr.
